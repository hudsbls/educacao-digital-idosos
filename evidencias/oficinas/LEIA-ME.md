# Evidências das oficinas — ACESSO RESTRITO

> **Esta pasta é ignorada pelo Git.** Nenhum arquivo aqui é versionado ou enviado ao GitHub.

## O que fica aqui

- Listas de presença (contêm nome e assinatura).
- Fotos das oficinas.
- Registros de dúvidas e diário de campo.

## Regras obrigatórias

1. **Fotos com rostos** só podem ser usadas com **autorização de uso de imagem** assinada.
   Sem autorização, use fotos de mãos, costas ou materiais.
2. **Listas de presença** nunca vão para o repositório. No relatório, apresente apenas
   **números agregados** (ex.: "24 participantes no total").
3. Para o relatório e o Git, copie somente a **seleção anonimizada** para
   `../` (evidências publicáveis), removendo dados pessoais.

Ver [`../../docs/GESTAO-E-REQUISITOS.md`](../../docs/GESTAO-E-REQUISITOS.md), Seção 5.3.
