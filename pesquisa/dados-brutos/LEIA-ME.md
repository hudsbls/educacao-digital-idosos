# Dados bruto de pesquisa — ACESSO RESTRITO

> **Esta pasta é ignorada pelo Git.** Nenhum arquivo aqui é versionado ou enviado ao GitHub.

## Por quê

Aqui ficam os dados coletados diretamente com participantes: questionários respondidos, transcrições
de entrevistas, áudios, planilhas com nome, telefone, endereço ou qualquer informação identificável.

Conforme a **LGPD** e os cuidados éticos do projeto
(ver [`../../docs/GESTAO-E-REQUISITOS.md`](../../docs/GESTAO-E-REQUISITOS.md), Seção 5.3):

- Dados brutos ficam **apenas neste computador / armazenamento institucional controlado**.
- **Nunca** publicar, compartilhar por link ou enviar para repositório.
- O que vai para o repositório é somente o material **anonimizado e agregado**, em
  `../analises/`.

## Antes de excluir ou mover qualquer arquivo daqui

Confirme com a coordenação do projeto. Estes dados são a base das evidências de impacto.
